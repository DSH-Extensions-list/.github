## Packages and attribution

DSH Visuals is the original inline chart and diagram extension inspired by rich conversational visuals; it includes its development source and a prebuilt package. It contains no OpenGhost code or assets. HTML Live Preview and Motion UI have been removed from this collection in favor of DSH Visuals. TheOne remains available for chat routing.

Package mirrors contain captured installed files and an `INSTALLED-PACKAGE.json` inventory. Their GitHub releases provide a package archive and SHA-256 checksum. See each mirror's `DISTRIBUTION.md` for its upstream project and details about included source files. Existing repositories retain their development history and release history. The subscriptions repository is an installation reference to the exact public npm version; its embedded upstream OAuth constants are not mirrored because GitHub push protection rejects them.

Original projects retain their authorship and licenses. Some mirrors contain built JavaScript without the complete development source. The recorded versions describe one installation and do not establish compatibility with other DSH versions or operating systems. No local account configuration, credentials, session history, or user data is included.
